# AIMC Glossary

| Term | Category | Meaning | Example |
|--------|----------|----------|----------|

| Object Inventory | DB2 | Collection of database objects available in a system | Tables, Views |
| Column Definition | DB2 | Description of a data attribute within an object | Business Key |
| View Definition | DB2 | Logical representation of data | Read-only business object |
| Package | Program | Database access definition bound from source code | Program access unit |
| Plan | Program | Runtime execution context | Application execution |
| Dependency | Methodology | Relationship between technical objects | Program uses View |
| Program | Program | Executable application component | Batch Program |
| Source Code | Program | Human-readable implementation | COBOL Source |
| Load Module | Program | Executable binary artifact | Production Module |
| Job | JCL | Batch execution unit | Nightly Processing |
| Step | JCL | Single execution within a job | Data Extraction |
| Procedure | JCL | Reusable execution definition | Standard Batch Flow |
| Repository | Tool | Centralized metadata source | Inventory System |
| Metadata | Methodology | Data describing system components | Object Attributes |
| Discovery | Methodology | Structured exploration of an unknown system | Application Analysis |
| Application Discovery | Methodology | Identification of application structures | Landscape Mapping |
| Data Discovery | Methodology | Identification of data structures | Data Model Analysis |
| Dependency Analysis | Methodology | Analysis of relationships between objects | Impact Assessment |
| Impact Analysis | Methodology | Evaluation of consequences of change | Change Planning |
| Knowledge Graph | Methodology | Connected representation of system knowledge | Relationship Map |
| Application | Application | Coherent set of programs and data supporting a business capability | Order Management |
| Application Group | Application | Logical grouping of related components | Functional Domain |
| Business Capability | Business | Functionality delivered to the organization | Procurement |
| Business Process | Business | Ordered sequence of business activities | Purchase Order Processing |
| Business Object | Business | Business-relevant entity represented by data | Order |
| Business Key | Business | Attribute uniquely identifying a business object | Order Number |
| Status | Business | Lifecycle state of a business object | Active |
| System Identifier | Business | Logical identifier of a business domain or system | Domain Code |
| Order Number | Business | Unique identifier of an order | PO-12345 |
| Order Item | Business | Line item within an order | Order Position |
| Quantity | Business | Measured amount of a business object | Ordered Quantity |
| Technical View | Application | Logical abstraction layer over physical data | Data Access View |
| Physical Table | DB2 | Physical persistence structure | Master Data Table |
| Alias | DB2 | Alternate object name | Compatibility Object |
| Index | DB2 | Access path optimization structure | Primary Key Index |
| Scheduler | Tool | Workload orchestration component | Batch Scheduler |
| Monitoring Tool | Tool | Runtime observation and diagnostics solution | Operations Console |
| Repository Browser | Tool | Interface for exploring metadata | Discovery Tool |
| Mainframe Environment | Application | Enterprise execution platform | Production Landscape |
| Mentoring | Methodology | Guided competence development | Knowledge Transfer |
| Competence Development | Methodology | Structured skill acquisition | Learning Path |
| Foundation Level | Methodology | Entry-level knowledge stage | Beginner |
| Practitioner Level | Methodology | Operational knowledge stage | Intermediate |
| Advanced Level | Methodology | Independent analysis stage | Senior |
| Expert Level | Methodology | Architecture and mentoring stage | Subject Matter Expert |
